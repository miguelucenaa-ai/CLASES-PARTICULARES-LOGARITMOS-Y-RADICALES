Calcula aplicando la definición

Llama x al logaritmo, escribe la potencia y pon los dos lados como potencias de la misma base. Los marcados con número son del ejercicio 14 del colegio (pág. 18).

log3⁡81

  1. Aplicamos la definición de logaritmo: el logaritmo de un número es el exponente al que hay que elevar la base para obtener dicho número. Planteamos la ecuación exponencial equivalente:

    3x=81

  2. Escribimos 81 como potencia de 3:

    3x=34

  3. Mismas bases, mismos exponentes:

    x=4
Resultado
log3⁡81=4

log2⁡116

  1. Aplicamos la definición de logaritmo: el logaritmo en base 2 de 116 es el exponente x al que hay que elevar la base 2 para obtener 116. Planteamos la ecuación:

    2x=116

  2. Como 16=24 y está dividiendo, 116=2−4:

    2x=2−4

  3. Igualamos exponentes:

    x=−4
Resultado
log2⁡116=−4

log13⁡27

  1. Aplicamos la definición de logaritmo: el logaritmo de un número es el exponente al que hay que elevar la base para obtener dicho número. Planteamos la ecuación exponencial equivalente:

    (13)x=27

  2. Todo en base 3: 13=3−1 y 27=33=332:

    3−x=332

  3. Igualamos exponentes:

    −x=32 ⇒ x=−32
Resultado
log13⁡27=−32

log2⁡(22)3

  1. Todo en base 2: 2=212 y 22=2⋅212=232. El argumento es:

    (22)3=(232)3=292

  2. Aplicamos la definición de logaritmo: el logaritmo de un número es el exponente al que hay que elevar la base para obtener dicho número. Planteamos la ecuación exponencial equivalente:

    (212)x=292 ⇒ 2x2=292

  3. Igualamos exponentes:

    x2=92 ⇒ x=9
Resultado
log2⁡(22)3=9

Otra forma: 22=(2)3, así que el argumento es (2)9 y el logaritmo vale 9.

Ln⁡(1e)−3

  1. Primero el argumento: 1e=e−1, así que (e−1)−3=e3:

    Ln⁡(1e)−3=Ln⁡e3

  2. Ln⁡ es base e, y ex=e3:

    x=3
Resultado
Ln⁡(1e)−3=3
log4⁡8

  1. Aplicamos la definición de logaritmo: el logaritmo de un número es el exponente al que hay que elevar la base para obtener dicho número. Planteamos la ecuación exponencial equivalente:

    4x=8

  2. Base común 2: 4=22 y 8=23:

    22x=23

  3. Igualamos exponentes:

    2x=3 ⇒ x=32
Resultado
log4⁡8=32
